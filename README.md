# Neural_machine_translation_Urdu_to_Roman_urdu


A simple Streamlit app that converts Urdu text to Roman Urdu.  
It supports:
- a **rule-based** transliteration fallback (works out-of-the-box), and
- optional loading of saved `model` and `tokenizer` files (if you have a trained neural transliteration model).
